# Day-2-of-100---Tip-Calculator
Day 2 of 100 days of code Python challenge with Angela Yu, Udemy Course

DESCRIPTION

A simple python script for calculating how to split a bill

This interactive script, asks the user for:
The total bill amount
The tip percentage
The number of people splitting the bill

The script then calculates the total bill including tip
Splits the final amount evenly among the group and rounds the result to 2 decimal places
Displays how much each person should pay

HOW TO RUN
- Copy code and run in your terminal
- Follow the prompts

PURPOSE
Part of a 100 Days of Code challenge, this project focuses on:

Handling user inputs,
Working with numbers (float and int) and performing calculations,
Formatting output with f-strings

SKILLS PRACTICED

Mathematical operations in Python
Type conversion (float(), int()) and string formatting
Building small interactive CLI programs
